# Worker 보고

Worker는 맡은 책임을 종료 보고 한 건으로 마칩니다.

정확한 응답 형식은 [Worker 보고 스키마](worker-report.schema.md)를 따릅니다.

`WORKER_FINAL_REPORT`는 종료 보고임을 나타낼 뿐 성공을 뜻하지 않습니다.

## 상태 의미

- `DONE`: 승인된 책임을 정상적으로 완료했습니다.
- `DONE_WITH_CONCERNS`: 책임은 완료했지만 오케스트레이터가 검토해야 할 문제가 있습니다.
- `OUT_OF_SCOPE`: 완료하려면 승인된 책임이나 소유권 밖의 작업이 필요합니다.
- `BLOCKED`: 범위 안의 작업을 이해했지만 실행을 계속할 수 없습니다.
- `NEED_CONTEXT`: `PROCEED` 이후 구현이나 검증을 진행하다가 완료에 필요한 정보가 부족해 안전한 지점에서 작업을 멈췄습니다.

## 테스트 요약

검증마다 목적, 대상, 방법, 실제 결과를 적습니다. 필요한 검증을 실행하지 못했다면 이유도 적습니다.

## 발견 사항

책임을 정할 때 예상하지 못한 사실이나 문제와 대응을 적습니다. 해당 사항이 없으면 `None.`을 적습니다.

## 파일

실제로 수정, 추가, 삭제한 파일을 모두 적습니다. 오케스트레이터는 이 목록을 선언된 소유권과 실제 저장소 diff와 대조합니다.
