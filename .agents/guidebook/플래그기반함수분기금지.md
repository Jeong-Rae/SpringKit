플래그로 동작을 선택하지 않습니다

플래그 값에 따라 함수가 서로 다른 작업을 수행하도록 만들지 않습니다.

Not:

fun dealCard(
    participant: Participant,
    hidden: Boolean,
) {
    val card = deck.draw()

    if (hidden) {
        participant.receiveHidden(card)
        return
    }

    participant.receive(card)
}

Do:

fun dealCard(player: Player) {
    player.receive(deck.draw())
}

fun dealHoleCard(dealer: Dealer) {
    dealer.receiveHoleCard(deck.draw())
}

서로 다른 동작에는 서로 다른 이름을 부여합니다.

플래그가 단순한 데이터 자체를 표현하는 경우까지 금지하지 않습니다. 플래그가 함수의 책임이나 실행 경로를 선택하는 경우에 함수를 분리합니다.
