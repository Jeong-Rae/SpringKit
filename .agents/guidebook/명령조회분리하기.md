명령과 조회를 분리합니다

함수는 상태를 변경하는 명령(Command) 또는 상태를 조회하는 쿼리(Query) 중 하나의 역할을 가져야 합니다.

조회 함수는 관찰 가능한 상태를 변경하지 않습니다.

fun score(): Score =
    hand.score()

상태 변경 함수는 상태 변경이라는 책임을 명확하게 표현합니다.

fun receive(card: Card) {
    hand.receive(card)
}

상태 변경과 조회를 하나의 함수에 결합하지 않습니다.

Not:

fun hitAndScore(player: Player): Score {
    player.receive(deck.draw())
    return player.score()
}

Do:

fun hit(player: Player) {
    player.receive(deck.draw())
}

fun score(player: Player): Score =
    player.score()

Command가 항상 Unit을 반환해야 하는 것은 아닙니다. 반환 타입보다 중요한 기준은 함수의 이름과 계약을 통해 상태 변경 여부를 예측할 수 있는지입니다.
