예외 처리 함수는 하나의 책임을 가집니다

예외를 처리하는 함수는 handle로 시작하고 어떤 실패를 처리하는지 이름에 표현합니다.

handleRestoreFailure(exception)
handleBetFailure(exception)
handleSettlementFailure(exception)

handleFailure처럼 대상이 없는 이름은 주변 맥락만으로 처리 대상이 명확한 경우에만 사용합니다.

예외 처리 함수에서는 정상적인 게임 진행을 수행하지 않습니다.

Not:

fun handleBetFailure(
    player: Player,
    exception: BetRejectedException,
) {
    recordBetFailure(player, exception)
    player.placeBet(minimumBet())
    game.startRound()
}

Do:

fun handleBetFailure(
    player: Player,
    exception: BetRejectedException,
) {
    recordBetFailure(player, exception)
    notifyBetFailure(player)
}

재시도, 보상, 대체 베팅과 같은 정책이 필요하다면 해당 정책을 책임지는 별도 함수나 객체에서 처리합니다.
