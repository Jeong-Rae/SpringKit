하나의 추상화 수준을 유지합니다

하나의 함수 안에서는 비슷한 수준의 개념을 다룹니다.

도메인 수준의 동작과 저수준 구현 세부 사항을 같은 함수에 섞지 않습니다.

Not:

fun startRound() {
    prepareDeck()

    players.forEach { player ->
        val card = deck.removeFirst()
        player.receive(card)
    }

    openPlayerTurn()
}

Do:

fun startRound() {
    prepareDeck()
    dealInitialCards()
    openPlayerTurn()
}

상위 함수에서는 prepareDeck, dealInitialCards, openPlayerTurn처럼 동일한 수준의 개념만 다룹니다.
