하나의 함수는 하나의 동작만 수행합니다

함수는 이름으로 표현한 하나의 작업을 수행해야 합니다.

함수 안에서는 그 작업보다 한 단계 아래에 있는 세부 작업만 다룹니다. 서로 다른 책임이나 지나치게 낮은 수준의 구현이 함께 나타나면 별도 함수로 분리합니다.

Not:

fun startRound() {
    deck.shuffle()

    players.forEach { player ->
        player.receive(deck.draw())
        player.receive(deck.draw())
    }

    dealer.receive(deck.draw())
    dealer.receive(deck.draw())

    if (dealer.hasBlackjack()) {
        settleRound()
    }
}

Do:

fun startRound() {
    prepareDeck()
    dealInitialCards()
    openPlayerTurn()
}

startRound는 라운드를 시작하는 흐름만 설명합니다. 덱 준비, 초기 카드 배분과 같은 세부 작업은 각각의 함수가 담당합니다.
