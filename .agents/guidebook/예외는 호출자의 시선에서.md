# 예외는 호출자의 시선에서

호출자가 예외를 받았을 때 어떻게 대응해야 하는지 판단할 수 있도록 예외를 구분합니다.

## 작성 지침

첫째, 피호출자가 던지는 예외는 호출자의 대응 방법을 기준으로 나눕니다. 호출자 기준이란 해당 예외를 받았을 때 무엇을 해야 하는지를 뜻합니다. 같은 요청을 다시 시도할 수 있는지, 입력이나 상태를 변경해야 하는지, 현재 작업을 중단해야 하는지를 구분합니다.

둘째, 예외 타입과 이름에는 호출자가 판단할 수 있는 실패의 의미를 드러냅니다. 발생한 기술이나 위치만으로 예외를 구분하지 않습니다. 대응이 다른 실패를 하나의 예외로 묶어 호출자가 메시지나 내부 원인을 해석하게 하지 않습니다. 호출자도 서로 다른 대응이 필요한 예외를 묶어 같은 방식으로 처리하지 않습니다.

셋째, 하위 계층의 예외가 호출자의 대응 방법을 설명하지 못한다면 공개하는 함수의 계약에 맞는 예외로 변환합니다. 호출자가 피호출자의 내부 구현이나 외부 라이브러리의 예외 규칙을 알아야만 대응할 수 없도록 합니다.

## Do Not 예시

```kotlin
class HttpException(cause: Throwable) : RuntimeException(cause) // Do Not: 통신 기술만 표현하고 호출자의 대응 의미 누락

fun currentQuote(symbol: String): Quote {
    try {
        return quoteClient.current(symbol)
    } catch (exception: SocketTimeoutException) {
        throw HttpException(exception) // Do Not: 시세 조회를 다시 시도할 수 있는지 드러나지 않음
    } catch (exception: InvalidSymbolFormatException) {
        throw HttpException(exception) // Do Not: 종목 코드 재입력이 필요한 실패도 같은 예외로 전달
    } catch (exception: QuoteAccessDeniedException) {
        throw HttpException(exception) // Do Not: 조회 권한 확보가 필요한 실패도 같은 예외로 전달
    }
}

val quote = currentQuote("00593O") // Do Not: 공개 예외만으로 잘못된 입력과 일시적 장애를 구분할 수 없음
```

```kotlin
class QuoteException(message: String, cause: Throwable) : RuntimeException(message, cause)

fun currentQuote(symbol: String): Quote {
    try {
        return quoteClient.current(symbol)
    } catch (exception: SocketTimeoutException) {
        throw QuoteException("RETRY", exception) // Do Not: 재시도 여부를 예외 타입 대신 문자열 규약으로 전달
    } catch (exception: InvalidSymbolFormatException) {
        throw QuoteException("INVALID_SYMBOL", exception) // Do Not: 재입력 여부를 같은 예외의 메시지로 구분
    }
}

try {
    currentQuote(symbol)
} catch (exception: QuoteException) {
    handleQuoteFailure(exception)
    if (exception.message == "RETRY") { // Do Not: 호출자가 메시지 규약을 해석해야 대응 가능
        quoteRetryQueue.add(symbol)
    }
}
```

```kotlin
fun currentQuote(symbol: String): Quote {
    try {
        return quoteClient.current(symbol)
    } catch (exception: SocketTimeoutException) {
        throw RetryableQuoteException(exception)
    } catch (exception: InvalidSymbolFormatException) {
        throw InvalidSymbolInputException(exception)
    } catch (exception: QuoteAccessDeniedException) {
        throw QuotePermissionRequiredException(exception)
    }
}

try {
    currentQuote(symbol)
} catch (exception: Exception) {
    when (exception) {
        is RetryableQuoteException,
        is InvalidSymbolInputException,
        is QuotePermissionRequiredException -> { // Do Not: 재시도, 재입력, 권한 확보가 필요한 예외를 묶어 처리
            handleQuoteFailure(exception)
            quoteRetryQueue.add(symbol) // Do Not: 잘못된 입력과 권한 부족도 그대로 재시도
        }
        else -> throw exception
    }
}
```

## Do 예시

```kotlin
class RetryableQuoteException(cause: Throwable) : RuntimeException(cause) // Do: 호출자의 재시도 가능성을 예외 타입으로 구분
class InvalidSymbolInputException(cause: Throwable) : RuntimeException(cause) // Do: 사용자 재입력이 필요한 실패 구분
class QuotePermissionRequiredException(cause: Throwable) : RuntimeException(cause) // Do: 조회 권한 확보가 필요한 실패 구분

fun currentQuote(symbol: String): Quote {
    try {
        return quoteClient.current(symbol)
    } catch (exception: SocketTimeoutException) {
        throw RetryableQuoteException(exception) // Do: 같은 조회 요청을 재시도할 수 있는 실패로 전달
    } catch (exception: InvalidSymbolFormatException) {
        throw InvalidSymbolInputException(exception) // Do: 잘못 입력한 종목 코드를 다시 입력할 대상으로 전달
    } catch (exception: QuoteAccessDeniedException) {
        throw QuotePermissionRequiredException(exception) // Do: 재입력이나 재시도가 아닌 권한 확보 대상으로 전달
    }
}
```

```kotlin
try {
    currentQuote(symbol)
} catch (exception: RetryableQuoteException) { // Do: 예외 타입만으로 재시도 가능 판단
    handleRetryableQuoteFailure(exception)
} catch (exception: InvalidSymbolInputException) { // Do: 예외 타입만으로 사용자 재입력 필요 판단
    handleInvalidSymbolInputFailure(exception)
} catch (exception: QuotePermissionRequiredException) { // Do: 예외 타입만으로 조회 권한 확보 필요 판단
    handleQuotePermissionRequiredFailure(exception)
}
```
