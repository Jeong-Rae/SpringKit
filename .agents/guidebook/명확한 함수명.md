함수의 계약을 이름으로 드러냅니다

서술적인 이름을 사용합니다

함수 이름만 보고 무엇을 하는지 알 수 있어야 합니다.

Not:

process()
handle()
execute()
check()

Do:

shuffleDeck()
dealInitialCards()
calculatePayout()
settleRound()

일반적인 동사보다 Blackjack 도메인에서 실제로 수행하는 동작을 표현합니다.

이름에 드러나지 않은 부수 효과를 만들지 않습니다

함수 이름으로 예상할 수 없는 상태 변경이나 외부 동작을 수행하지 않습니다.

Not:

fun hasBlackjack(player: Player): Boolean {
    if (player.hasBlackjack()) {
        player.receivePayout(blackjackPayout())
        return true
    }

    return false
}

hasBlackjack이라는 이름에서는 상태 조회만 예상할 수 있지만 실제로는 플레이어의 칩까지 변경합니다.

Do:

fun hasBlackjack(player: Player): Boolean =
    player.hasBlackjack()

fun settleBlackjack(player: Player) {
    if (!hasBlackjack(player)) {
        return
    }

    player.receivePayout(blackjackPayout())
}

함수 이름과 실제 동작을 일치시켜 호출자가 상태 변경 여부를 예측할 수 있도록 합니다.
