조건식은 리뷰어가 구현 세부를 직접 해석하지 않아도 코드의 판단 의도를 즉시 이해할 수 있도록 작성합니다. 즉, 조건식의 핵심 목적은 계산 과정이 아니라 의미를 드러내는 데 있습니다. `if`에서 사용하는 조건은 의미를 나타내는 boolean 지역 변수로 먼저 표현하고, 변수명은 `is`, `has`, `can`, `should`와 같은 predicate 접두사를 사용하여 판단 결과를 직관적으로 나타냅니다. 여러 조건은 의미가 구분되는 판단 단위로 나누고, 관련된 predicate 변수를 조합하여 하나의 최종 조건 변수로 표현합니다. 메서드 호출이나 스트림 연산처럼 구현 내용을 읽어야 의미를 파악할 수 있는 조건도 해당 판단의 목적을 나타내는 predicate 변수로 추상화합니다. 단순한 `null` 비교나 상태 비교는 표현 자체에서 의미가 충분히 드러나는 형태로 사용합니다.

예:

```java
var isDealerTurn = turn == Turn.DEALER;
var hasScoreBelowSeventeen = dealer.score() < 17;
var shouldHit = isDealerTurn && hasScoreBelowSeventeen;
```
