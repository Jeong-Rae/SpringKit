# 플래그로 선택하는 동작을 함수로 분리하기

호출자가 함수 이름만으로 요청하는 동작을 알 수 있게 합니다.

## 작성 지침

인자 값으로 서로 다른 동작을 선택하지 않습니다. 동작마다 함수를 분리해 이름으로 의도를 드러내고, 필요한 입력과 검증을 각각 둡니다. 참/거짓인 데이터 자체를 전달하는 경우는 허용합니다.

## Do Not 예시

```kotlin
fun submitBuyOrder(
    symbol: String,
    quantity: Long,
    market: Boolean,
    price: Long? = null,
) {
    if (market) { // Do Not: 플래그로 주문 방식 선택
        orderGateway.submit(MarketBuyOrder(symbol, quantity))
    } else {
        val limitPrice = requireNotNull(price)
        require(limitPrice > 0)
        orderGateway.submit(LimitBuyOrder(symbol, quantity, limitPrice))
    }
}

submitBuyOrder("005930", 10, market = true)
submitBuyOrder("005930", 10, market = false, price = 70_000)
```

## Do 예시

```kotlin
fun submitMarketBuyOrder(symbol: String, quantity: Long) { // Do: 이름으로 주문 방식 구분
    orderGateway.submit(MarketBuyOrder(symbol, quantity))
}

fun submitLimitBuyOrder(symbol: String, quantity: Long, price: Long) {
    require(price > 0) // Do: 지정가 가격 검증을 해당 함수에 배치
    orderGateway.submit(LimitBuyOrder(symbol, quantity, price))
}

submitMarketBuyOrder("005930", 10)
submitLimitBuyOrder("005930", 10, price = 70_000)
```
