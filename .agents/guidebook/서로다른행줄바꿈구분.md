서로 다른 개념은 빈 행으로 구분합니다

빈 행은 코드 안의 개념적 경계를 표현합니다.

서로 강하게 연관된 코드는 붙여 두고, 처리 단계나 의미가 달라지는 지점에는 빈 행을 둡니다.

Not:

fun settleRound() {
    val results = calculateResults()
    results.forEach(::applyResult)
    game.finishRound()
    eventPublisher.publish(RoundFinished(game.id))
}

Do:

fun settleRound() {
    val results = calculateResults()
    results.forEach(::applyResult) // 결과를 계산하고 정리하는 부분
    // 빈 줄 구분
    game.finishRound() // 게임 라운드를 마무리
    // 빈 줄 구분
    eventPublisher.publish(RoundFinished(game.id)) // 이벤트 발행
}

같은 개념을 구성하는 문장 사이에는 불필요한 빈 행을 넣지 않습니다.
