상태를 노출하지 않고 의미 있는 행동을 제공합니다

객체를 단순한 데이터 저장소로 사용하지 않습니다. 객체가 책임지는 상태는 객체 내부에 숨기고, 그 상태를 사용하는 의미 있는 행동을 제공합니다.

Not:

class Hand(
    val cards: MutableList<Card>,
)

fun hit(
    player: Player,
    deck: Deck,
) {
    player.hand.cards += deck.draw()
}

호출자가 Hand의 내부 표현을 직접 알고 변경해야 합니다.

Do:

class Hand(
    cards: List<Card> = emptyList(),
) {

    private val cards = cards.toMutableList()

    fun receive(card: Card) {
        cards += card
    }

    fun score(): Score =
        ScoreCalculator.calculate(cards)

    fun isBust(): Boolean =
        score() > Score(21)
}

객체를 사용하는 쪽에서는 내부 컬렉션을 직접 조작하지 않습니다.

class Player(
    private val hand: Hand,
) {

    fun receive(card: Card) {
        hand.receive(card)
    }

    fun score(): Score =
        hand.score()

    fun isBust(): Boolean =
        hand.isBust()
}

호출자는 카드가 어떤 자료 구조에 저장되는지 알 필요가 없습니다.

player.receive(deck.draw())

if (player.isBust()) {
    finishTurn(player)
}

객체의 내부 표현보다 객체가 제공하는 도메인 행동을 사용합니다.
