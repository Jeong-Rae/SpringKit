내려가기 규칙을 따릅니다

코드는 위에서 아래로 읽으면서 점차 구체적인 내용을 만나도록 구성합니다.

상위 함수는 전체 흐름을 설명하고, 아래로 내려갈수록 세부 구현을 배치합니다.

fun startRound() {
    prepareDeck()
    dealInitialCards()
    openPlayerTurn()
}

private fun prepareDeck() {
    resetDeck()
    shuffleDeck()
}

private fun dealInitialCards() {
    dealPlayers()
    dealDealer()
}

private fun openPlayerTurn() {
    game.openPlayerTurn()
}

startRound만 읽어도 라운드가 시작되는 전체 흐름을 이해할 수 있어야 합니다.

같은 계층의 개념을 먼저 배치합니다

BFO(Breadth-First Ordering)를 적용하여 같은 계층의 개념을 먼저 배치하고 그 아래의 세부 개념으로 내려갑니다.

예:

startRound
    prepareDeck
    dealInitialCards
    openPlayerTurn

prepareDeck
    resetDeck
    shuffleDeck

dealInitialCards
    dealPlayers
    dealDealer

상위 흐름을 구성하는 prepareDeck, dealInitialCards, openPlayerTurn을 먼저 이해한 뒤 각 작업의 세부 구현으로 내려갈 수 있어야 합니다.

강하게 연관된 코드는 가까이 배치합니다

서로 강하게 연관된 함수는 가능한 한 가까운 위치에 둡니다.

한 함수가 다른 함수를 직접 호출한다면 관련 함수를 파일의 먼 위치에 분산하지 않습니다.

Not:

fun settleRound() {
    calculateResults()
    payWinners()
}

// unrelated methods...

private fun calculateResults() {
    ...
}

// more unrelated methods...

private fun payWinners() {
    ...
}

Do:

fun settleRound() {
    calculateResults()
    payWinners()
}

private fun calculateResults() {
    ...
}

private fun payWinners() {
    ...
}

같은 계층의 함수 배치와 연관 코드의 근접성이 충돌한다면 전체 흐름을 먼저 이해할 수 있도록 상위 계층의 구조를 우선합니다.
