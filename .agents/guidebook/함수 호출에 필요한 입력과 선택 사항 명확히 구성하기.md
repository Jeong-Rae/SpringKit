# 함수 호출에 필요한 입력과 선택 사항 명확히 구성하기

호출자가 필요한 값을 전달하면서 내부 조건과 구현 세부를 기억할 부담을 줄입니다.

## 작성 지침

첫째, 업무 의미가 있는 객체는 스칼라 값으로 쪼개지 않고 그대로 전달합니다. 호출에 필요한 기존 객체를 조합합니다. 인자 수를 줄이기 위한 중간 전달용 객체를 추가하지 않습니다.

둘째, 독립적인 선택 기능은 각각 선택할 수 있게 구성합니다. 기능과 업무 목적을 이름에 드러냅니다. 사용하지 않는 기능의 입력을 요구하거나 기능 조합마다 함수를 추가하지 않습니다.

셋째, 호출에 필요한 핵심 입력만 함수 인자로 받습니다. 발송 설정과 실행은 실행 객체가 관리하며, 필요한 의존성은 객체를 구성할 때 전달합니다. 호출자가 결정할 필요 없는 값은 내부에서 생성하고, 호출마다 달라지는 값은 해당 호출에서 전달합니다.

넷째, 선택 기능은 기능 단위의 공개 메서드로 설정하고 마지막에 핵심 동작을 호출합니다. 각 기능을 선택할 때 필요한 값만 전달하고 해당 실행 객체에 설정을 보관합니다. 설정을 생략하면 합의된 기본 동작을 수행하도록 구성합니다. 호출자가 내부 구현이나 설정 조합의 주의 사항을 찾아보지 않아도 공개 메서드만으로 사용법을 알 수 있어야 합니다.

호출만 읽어도 전달하는 객체의 의미와 선택한 기능을 알 수 있는지 확인합니다. 선택 기능이 없는 간단한 호출은 필요한 객체를 직접 전달합니다.
