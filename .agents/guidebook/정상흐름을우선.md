try-catch-finally에서도 정상 흐름을 먼저 드러냅니다

try-catch-finally를 사용할 때도 정상적인 실행 흐름을 가장 먼저 읽을 수 있도록 구성합니다.

try에는 정상 동작을 두고, catch에는 실패 처리만 두며, finally에는 성공과 실패에 관계없이 반드시 수행해야 하는 정리 작업만 둡니다.

fun settleRound(roundId: RoundId) {
    try {
        settle(roundId)
    } catch (exception: RetryableGameException) {
        handleSettlementFailure(
            roundId,
            exception,
        )
    } finally {
        releaseRoundLock(roundId)
    }
}

try 내부에서는 정상 흐름을 함수로 표현합니다.

private fun settle(roundId: RoundId) {
    val round = requireRound(roundId)

    calculateResults(round)
    payWinners(round)
    finishRound(round)
}

catch 내부에서는 예외 처리만 수행합니다.

private fun handleSettlementFailure(
    roundId: RoundId,
    exception: RetryableGameException,
) {
    recordSettlementFailure(
        roundId,
        exception,
    )

    scheduleSettlementRetry(roundId)
}

finally에서는 성공 여부와 관계없이 필요한 정리 작업을 수행합니다.

private fun releaseRoundLock(
    roundId: RoundId,
) {
    roundLock.release(roundId)
}

예외 처리 때문에 정상적인 비즈니스 흐름이 여러 try-catch 블록 사이에 흩어지지 않도록 합니다.
