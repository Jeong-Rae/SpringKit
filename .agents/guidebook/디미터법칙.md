디미터 법칙을 준수합니다

객체는 자신이 직접 알고 있는 객체와만 협력합니다.

다른 객체의 내부 객체를 얻어 다시 그 객체의 내부로 들어가는 호출 체인을 만들지 않습니다. 필요한 행동은 가장 가까운 협력 객체에 요청합니다.

Not:

if (game.table.player.hand.score() > Score(21)) {
    ...
}

호출자가 Game, Table, Player, Hand의 내부 구조를 모두 알고 있습니다.

Do:

if (game.isBust(playerId)) {
    ...
}

또는 Player와 직접 협력하는 상황이라면 다음과 같이 작성합니다.

if (player.isBust()) {
    ...
}

필요한 행위가 내부 객체에 존재한다면 가까운 객체가 이를 위임합니다.

class Player(
    private val hand: Hand,
) {

    fun isBust(): Boolean =
        hand.isBust()
}

디미터 법칙의 목적은 단순히 점(.)의 개수를 줄이는 것이 아닙니다. 호출자가 다른 객체의 내부 구조에 결합되지 않도록 협력 경계를 유지하는 것이 목적입니다.
