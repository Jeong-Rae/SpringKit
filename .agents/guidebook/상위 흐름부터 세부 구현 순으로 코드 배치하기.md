# 상위 흐름부터 세부 구현 순으로 코드 배치하기

코드를 위에서 아래로 읽으며 전체 흐름을 먼저 파악하고 세부 구현을 확인할 수 있게 합니다.

## 작성 지침

첫째, 전체 흐름을 설명하는 상위 코드를 먼저 배치합니다. 하위 코드의 수준은 동일한 추상화 수준의 기준으로 판단합니다.

둘째, 같은 추상화 수준의 하위 코드를 먼저 모아 배치한 뒤, 더 낮은 수준의 코드를 배치합니다. 이 프로젝트에서는 이 순서를 BFO(Breadth-First Ordering, 너비 우선 배치)라고 합니다.

셋째, 관련 코드는 가까이 배치하고 관계없는 코드를 사이에 끼우지 않습니다. 근접 배치와 같은 수준의 코드 배치가 충돌하면 같은 수준의 코드를 먼저 보여 주는 순서를 우선합니다.

## Do Not 예시

```kotlin
fun chargeCommission(trade: Trade) {
    val amount = calculateCommission(trade)
    debitCommission(trade, amount)
    publishCommissionCharged(trade, amount)
}

private fun calculateCommission(trade: Trade): Long {
    val rate = commissionRate(trade)
    return commissionAmount(trade, rate)
}

private fun commissionRate(trade: Trade): Double = ... // Do Not: 같은 수준의 함수보다 세부 계산을 먼저 배치
private fun commissionAmount(trade: Trade, rate: Double): Long = ...

fun updateWatchlist() { ... } // Do Not: 수수료 처리 사이에 관계없는 코드 배치

private fun debitCommission(trade: Trade, amount: Long) { ... }
private fun publishCommissionCharged(trade: Trade, amount: Long) { ... }
```

## Do 예시

```kotlin
fun chargeCommission(trade: Trade) {
    val amount = calculateCommission(trade)
    debitCommission(trade, amount)
    publishCommissionCharged(trade, amount)
}

private fun calculateCommission(trade: Trade): Long {
    val rate = commissionRate(trade)
    return commissionAmount(trade, rate)
}

private fun debitCommission(trade: Trade, amount: Long) { ... } // Do: 계산과 같은 수준의 부과 단계 배치
private fun publishCommissionCharged(trade: Trade, amount: Long) { ... } // Do: 같은 수준의 발행 단계까지 배치

private fun commissionRate(trade: Trade): Double = ... // Do: 더 낮은 수준의 계산을 아래에 배치
private fun commissionAmount(trade: Trade, rate: Double): Long = ...

fun updateWatchlist() { ... } // Do: 관계없는 코드는 수수료 처리 밖에 배치
```
