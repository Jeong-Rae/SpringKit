# 조건문 중첩을 제한하고 다중 분기를 정리하기

정상 흐름을 깊은 들여쓰기 없이 읽을 수 있게 합니다.

## 작성 지침

첫째, 조건문의 중첩은 최대 2단계로 제한합니다. 이를 넘으면 분기별 작업을 함수로 분리하거나 조건 구조를 다시 설계합니다.

둘째, 같은 값이나 조건을 기준으로 분기가 3개 이상 나뉘면 `when`을 사용합니다.

## Do Not 예시

```kotlin
fun submitBuyOrder(order: BuyOrder) {
    if (account.isActive()) {
        if (market.isOpen()) {
            if (account.canBuy(order)) { // Do Not: 조건문을 3단계로 중첩
                account.reserve(order.amount)
                orderGateway.submit(order)
            } else {
                rejectBuyOrder(order)
            }
        }
    }
}
```

```kotlin
fun notifyBuyOrder(order: BuyOrder) {
    if (order.status == OrderStatus.ACCEPTED) { // Do Not: 같은 값의 3개 분기를 if-else로 나열
        notification.sendAccepted(order)
    } else if (order.status == OrderStatus.FILLED) {
        notification.sendFilled(order)
    } else if (order.status == OrderStatus.CANCELLED) {
        notification.sendCancelled(order)
    }
}
```

## Do 예시

```kotlin
fun submitBuyOrder(order: BuyOrder) {
    if (account.isActive() && market.isOpen()) { // Do: 선행 조건을 묶어 중첩 축소
        if (account.canBuy(order)) {
            account.reserve(order.amount)
            orderGateway.submit(order)
        } else {
            rejectBuyOrder(order)
        }
    }
}
```

```kotlin
fun notifyBuyOrder(order: BuyOrder) {
    when (order.status) { // Do: 같은 값의 3개 분기를 when으로 표현
        OrderStatus.ACCEPTED -> notification.sendAccepted(order)
        OrderStatus.FILLED -> notification.sendFilled(order)
        OrderStatus.CANCELLED -> notification.sendCancelled(order)
    }
}
```
